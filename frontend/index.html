本機橋接

還沒偵測到本機橋接

出題和判定要用你電腦上的 AI（Claude Code / Codex / Ollama），需要在電腦上執行一個小程式「橋接」：

已經安裝過：直接按「啟動橋接」，瀏覽器第一次會問要不要開啟，按允許。

第一次使用（Windows）：

  1. 下載橋接並解壓縮
  2. 雙擊裡面的 Install-Learn-Bridge.bat（只要一次；沒有 uv 會詢問是否自動安裝，第一次會下載約 400 MB）
  3. 安裝完會自動啟動；之後都只要按「啟動橋接」

macOS / Linux：解壓縮後在資料夾執行 uv run learn3d-bridge。橋接只監聽你的電腦（127.0.0.1），AI 不能讀寫檔案或執行指令。Chrome 若詢問「存取本機網路」請按允許。
