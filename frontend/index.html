偵測中…

    橋接有新版本

    手動下載新版

    橋接已經開著還是連不上？可能是瀏覽器擋住了這個網站連到你的電腦（127.0.0.1）。

    按網址列左邊的圖示 →「網站設定」→ 把「本機網路存取」（Local network access）改成「允許」，回來按「重新偵測」。不想改設定，也可以直接開橋接提供的本機版網頁。

    開啟本機版（127.0.0.1:8766）

    還沒安裝？（Windows，只要一次）

    1. 準備一個 AI：有 Claude Pro 或 Max 訂閱最簡單（橋接已內建 Claude Code，裝好後在這個面板按「登入 Claude Code」就好）；也可以用 Codex CLI 或免費的 Ollama 本機模型。
    2. 下載本機橋接（zip），解壓縮後雙擊 Install-Learn-Bridge.bat。沒有 uv 會詢問是否自動安裝；第一次會下載約 400 MB。
    3. 安裝完會自動啟動。之後只要按上面的「啟動橋接」（瀏覽器第一次會問要不要開啟連結，選允許；Chrome 問「存取本機網路」也選允許）。

    macOS / Linux：解壓縮後在資料夾執行 uv run learn3d-bridge，保持終端機開著。

    橋接只監聽你的電腦（127.0.0.1），AI 不能讀寫檔案或執行指令；不需要任何 API key。沒連上時網站用示範資料（英文文法）瀏覽。
